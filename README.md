# Gift Offer Bot

## Что умеет
- Принимает ссылку на NFT-подарок.
- Запрашивает сумму и валюту (⭐ или TON).
- Создаёт сообщение с кнопками «Отклонить» и «Принять».
- Сообщает создателю предложения об ответе.

## Важно
Это демонстрационный бот: кнопки только фиксируют ответ. Они НЕ передают NFT, не списывают звёзды/TON и не подтверждают оплату. Не выдавай сообщение за реальное подтверждение сделки.

## Запуск
1. Создай бота через @BotFather и скопируй токен.
2. В панели хостинга создай переменную окружения `BOT_TOKEN` со значением токена.
3. Загрузи файлы проекта.
4. Команда запуска: `npm start`.

Локально (если понадобится):
1. Установи Node.js.
2. Выполни `npm install`.
3. Скопируй `.env.example` в `.env` и вставь токен.
4. Выполни `npm start`.

Для уведомлений создатель предложения должен хотя бы один раз открыть бота и нажать `/start`.
Предложение можно переслать продавцу из чата с ботом. Ответить на кнопки сможет получатель пересланного сообщения.
Данные предложений хранятся в памяти процесса и сбрасываются при перезапуске бота.
